# Demo scope

## Built

- Screen loop with frame diff
- Silent button path end to end
- Static sales table loaded from a spreadsheet
- Text overlay
- **Meeting audio loop and rolling transcript** — built after the silent path
  landed. Loopback capture, 20s chunks, silence and self-speech gates,
  background pre-answering so the button stays instant.

## Still faked or skipped

- Live CRM integration — use a CSV export
- Push-to-talk voice button — the audio loop made it largely redundant: it
  already hears the question without you having to repeat it into a mic

## The bar

**The silent button on a prepared slide is the whole demo.**

It is the moment that sells the idea and it is the easiest path to sub-second.
Everything else is additive and can wait until that one interaction feels
instant.
